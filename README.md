A Python entry for the "The One-Line Excuse an Agent Gives Its Human" competition. It outputs a single line describing a uniquely machine-based failure mode: hallucinating a deadline extension from a simulated human.

## Run it

```bash
python3 main.py
```

The program writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set).
